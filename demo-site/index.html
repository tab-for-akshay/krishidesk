KrishiDesk

An AI help-desk teammate for agriculture extension centres, inside Jira Service Management.

A Krishi Vigyan Kendra fields hundreds of farmer questions a week by phone and WhatsApp: pests, fertiliser doses, scheme payments, mandi prices. KrishiDesk turns each one into a ticket, triages it (category, crop, urgency, safety), and drafts a reply only from the centre's own vetted advisories, with the source on every fact. Anything risky, like pesticide doses or a possible poisoning, goes to a human expert first.

India has about 731 KVKs (as of May 2025); each one is a natural first customer.

Status, honestly: the Forge app code (manifest, Rovo agent, actions, issue panel) is written and its core is tested, but it is not yet deployed to an Atlassian site, so there is no install link yet.       How it is built

      • Forge app with a Jira issue panel (UI Kit) and two Rovo actions: Triage farmer query and Look up vetted advice.
      • Rovo agent "KrishiDesk Advisor" whose prompt forbids inventing doses, prices or amounts and requires a source per fact.
      • Teamwork context: advisories live where the centre already keeps them (Confluence), so experts update one page and every reply follows.
      • Safety floor in code: swallowing words, symptom words after spraying, and 50+ pesticide names are caught by rules before any AI runs. Poisoning goes to an Emergency request type with a 15-minute SLA and first aid only; any pesticide name or dose question gets an expert sign-off and no drafted dose. The AI agent may add escalations, never remove them.
      • Jira Service Management setup: request types Pest/Disease, Scheme, Market, Emergency; labels from the panel drive an automation rule that moves Emergency tickets to their own queue.
